# Projeto DOM JavaScript

Atividade para praticar manipulação do DOM com JavaScript.

## Tarefas

1 - Mostrar nome digitado  
2 - Alterar texto com botão  
3 - Adicionar itens em uma lista  
4 - Lista de tarefas com validação  
5 - Remover tarefas  
6 - Marcar tarefas como concluídas

## Tecnologias

HTML  
JavaScript  
Bootstrap
